# Security policy

## Reporting a vulnerability

Use this repository's **Security → Report a vulnerability** flow to send a
private report. Do not open a public issue for a vulnerability that could
expose signing credentials, private user files, unsafe archive handling, or a
practical code-execution path.

Include:

- the affected BanjoPad commit;
- device and OS version;
- a minimal reproduction;
- expected impact; and
- logs with credentials, personal paths, ROM data, saves, and generated game
  material removed.

Never upload a ROM, generated recompilation input, save, texture pack,
provisioning profile, certificate, private key, signed IPA, or extracted
copyrighted asset as proof.

General gameplay defects and non-sensitive crashes should use the public bug
template instead.
